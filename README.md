## 日本云服务器的线路差异：不只是"快"和"慢"

### CN2 GIA、CN2 GT、BGP 到底什么区别

CN2 是中国电信的精品网，但分两档。**CN2 GIA**（Global Internet Access）全程走59.43开头的专属节点，从国际出口到省级、市级线路都是独立的，晚高峰不会切到拥堵的163骨干网。延迟稳定在60-90ms左右。

**CN2 GT**（Global Transit）去程可能走CN2，但进入国内后会切换到202.97开头的163网络。晚高峰时段延迟会明显上升，丢包率也跟着走高。

**BGP 住宅线路**是另一个方向：不走电信专线，而是接入日本本地ISP的住宅网络。IP段干净，能解锁Netflix、TikTok这类有地域检测的平台，但回国延迟通常比CN2 GIA高10-20ms。

如果你在做游戏加速、视频会议、实时数据同步，CN2 GIA的稳定性值这个溢价。如果主要需求是内容分发、社交媒体运营、跨境电商店铺，BGP住宅IP的解锁能力更实用。

### 原生IP和广播IP的实际差别

原生IP是机房所在国家/地区ISP直接分配的地址段，在Netflix、Disney+、TikTok的检测系统里被认定为"本地用户"。广播IP是通过BGP宣告从其他地区路由过来的，平台能看出来。

如果你需要运营日本区TikTok账号、测试日本本土广告投放效果、或者给日本用户提供流媒体服务，原生IP是硬性要求。只是搭个网站或跑个API服务，广播IP完全够用，而且通常便宜30-50%。

部分商家提供的日本VPS标注"原生双ISP"，表示同时接入两家日本本地运营商，路由冗余度更高。购买前可以先用测试IP确认：如果是日本原生IP，whois查询会显示日本ISP的AS号和地址信息。

## 购买时容易忽略的几个细节

### 带宽标注里的"Mbps"和实际能跑多少

商家标的100Mbps、200Mbps是端口带宽上限，不是承诺速率。实际下载速度还要看对端服务器的出口、运营商之间的Peer关系、以及当时的网络拥堵情况。

从国内电信100M家庭宽带访问100Mbps VPS，实际下载速度通常在10-15MB/s（80-120Mbps），因为国际出口和回程线路会成为瓶颈。如果你需要跑满带宽，测试时记得用国内多个地区、不同运营商的节点分别测，别只在自己办公室测一遍就下单。

### 月流量是按什么算的、超了会怎样

出站流量（从服务器发出）计费，入站流量（上传到服务器）不计。1TB换算成每天约33GB，如果跑个WordPress网站、每天1000个UV、平均每页加载2MB静态资源，差不多能承载500个访问。但如果做视频分发、软件下载、或者图片CDN，1TB可能一周就用完。

超出流量后通常会限速而不是直接断网。Zorocloud的处理方式是限速到1Mbps，对应下载速度约128KB/s，基本只能维持最低限度的SSH连接和文本网页访问。如果你的业务对流量波动敏感，与其每次被限速影响体验，不如一开始就选流量更大的套餐。

### 能不能换IP、换几次、要不要加钱

原生住宅IP被墙的概率比数据中心IP低，但不是零。购买前问清楚：如果IP不可用（被墙、被平台封禁、进了某些服务的黑名单），商家能否更换IP、更换是否收费、多久能换好、一共能换几次。

有些商家提供1-2次免费更换，超出后按次收费（通常5-15元/次）。也有商家不提供更换服务，遇到问题只能退款重买。这个政策直接影响你的实际使用成本，尤其是做TikTok、跨境电商这类对IP质量敏感的业务。
